# UX documentation

The target UX of the app (the design brief calls it *Jingle Keys*; in this repository it is Snezhnye Noty) and the brief for auditing the implementation against it. These files describe where the UX should go, not the results of an audit, except `AUDIT.md`.

| File | What it holds |
|---|---|
| [UX-SPEC.md](UX-SPEC.md) | Navigation, states and visual rules |
| [ACCEPTANCE.md](ACCEPTANCE.md) | The 21-point acceptance checklist |
| [navigation.mmd](navigation.mmd) | Mermaid state diagram of the navigation |
| [AGENT-AUDIT.md](AGENT-AUDIT.md) | Self-contained brief for an agent auditing the implementation |
| [AUDIT.md](AUDIT.md) | First gap analysis of the code against the spec, with links to the GitHub issues |

Target device: Huawei MatePad 11, 2560×1600 physical pixels, 16:10, base layout 1280×800. Four themes: Pixel Quest, Music Buddies, Winter Melody, Anime Music Academy.

The original documents were written in Russian; the files here are English translations. When the spec changes, update these files and the acceptance checklist together.
