# Acceptance checklist (21 criteria)

## Navigation
- [ ] Relaunching the app restores the profile.
- [ ] The game starts with one tap once permissions are granted.
- [ ] There are no unnecessary intermediate screens.
- [ ] Every screen has one main action.
- [ ] Going back is predictable.

## Gameplay
- [ ] Waiting for a note does not change the screen.
- [ ] The right note continues the game automatically.
- [ ] Pause keeps the game context.
- [ ] The microphone does not need to be set up again without a reason.
- [ ] A wrong note does not cause a negative reaction.

## Progress
- [ ] The reward ends the game scene naturally.
- [ ] The next action depends on the result.
- [ ] A new level opens in a visually clear way.
- [ ] Changing the theme does not reset progress.
- [ ] Every profile has its own progress.

## Look and tablet
- [ ] All four themes use the same navigation.
- [ ] Buttons keep their meaning and position.
- [ ] Decorations do not cover the notes.
- [ ] Nothing is clipped on the MatePad 11.
- [ ] Animations are smooth and do not block actions.
- [ ] The interface is understandable without reading text.
